# Guia de Campo Vogt

Guia de sobrevivência, primeiros socorros, água, temporal e enchente, plantas medicinais e mochila de emergência. Funciona sem internet.

## Baixar no celular
Abra no navegador do celular e toque em baixar:

https://github.com/cassianovogt123-ai/Guia-sobreviv-ncia-/releases/latest/download/Guia-de-Campo-Vogt.html

Depois é só abrir o arquivo baixado. Não precisa de internet.

Este guia não substitui atendimento médico. Emergência: 192 (SAMU), 193 (Bombeiros), 199 (Defesa Civil).
