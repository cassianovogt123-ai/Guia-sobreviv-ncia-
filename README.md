# Guia de Campo Vogt

Guia de sobrevivência, primeiros socorros, água, temporal e enchente, plantas medicinais e mochila de emergência. Funciona sem internet.

## Baixar no celular
1. Abra no navegador do celular: https://github.com/cassianovogt123-ai/Guia-sobreviv-ncia-/blob/main/Guia-de-Campo-Vogt.html
2. Toque no botão de download (seta para baixo, "Download raw file").
3. Abra o arquivo baixado pelo navegador. Não precisa de internet.

Este guia não substitui atendimento médico. Emergência: 192 (SAMU), 193 (Bombeiros), 199 (Defesa Civil).
